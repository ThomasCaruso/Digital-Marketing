# Long Nguyen–inspired V1 concept

This folder is an isolated website concept for Thomas Caruso's Digital Marketing project.

## Isolation
- Branch: `chatgpt/long-nguyen-v1`
- Folder: `concept-long-v1/`
- No files on `main` were changed.
- This concept is intentionally separate from any other agent work.

## Design direction
Inspired by the editorial/minimal structure of https://long-nguyen.dev/:
- oversized typography
- sparse navigation
- strong whitespace
- selected-work rows
- restrained interactions
- black / warm-neutral palette with one accent color

The implementation does not copy the reference site's text, branding, assets, or proprietary code.

## Files
- `index.html`
- `style.css`
- `script.js`
- expected local asset: `profile.jpg`

If `profile.jpg` is not present, the page gracefully displays a TC fallback monogram instead of a broken image.

## Content source
Professional content is based on the latest resume available for Thomas Caruso. External professional links are limited to previously supplied GitHub and LinkedIn URLs.
